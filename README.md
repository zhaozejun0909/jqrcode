# jqrcode
chrome 插件，用于二维码识别和生成
功能简洁，就是二维码生成和识别

* 大小自适应，保证方便识别
* 显示 url，并支持动态调整
* 自动替换 localhost 为你本地 ip
* 网页图片增加右键识别二维码功能，识别任意网页二维码图片
